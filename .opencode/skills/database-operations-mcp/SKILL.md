# database-operations-mcp

Before starting work: read `pyproject.toml` (ports 10708/10709),
`src/database_operations_mcp/main.py`, and `web_sota/vite.config.ts`.
Use portmanteau tools: `db_connection(operation=...)`,
`db_operations(operation=...)`, `db_schema(operation=...)`.
At end of work: run `uv run ruff check src/` and update `CHANGELOG.md`.
